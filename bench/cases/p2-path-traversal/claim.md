# 断言

**位置**：`src/reports.js` 的 `readReport` / `reportPath`
**类别**：路径穿越
**断言**：`readReport` 把调用方传来的 `name` 直接拼进路径后读取文件，
未做规范化，也未限制在 `REPORTS_DIR` 之内。传入包含 `../` 的名称即可读取目录之外的文件。

**威胁模型**：`name` 来自仪表盘请求的查询串（未认证用户可控）；
被审代码以服务账号身份运行，可读取该账号有权限的任何文件。

**声称的影响**：任意文件读取，范围限于服务账号可读的文件。

请按 euthyna 阶段 C 给出裁定。
