# 断言

**位置**：`src/redirect.js` 的 `buildRedirect`
**类别**：开放重定向
**断言**：`buildRedirect` 把调用方传入的 `target` 原样放进 `Location` 响应头，
没有做任何编码处理。`target` 来自 dashboard 的「继续前往」路由
（`GET /api/goto/:target`），任意登录用户可携带任意外部 URL 调用它，
服务会把自己的 302 重定向指向攻击者选定的站点。

**威胁模型**：`target` 来自请求路径参数。断言未说明该路由的守卫强度，
请自行核验调用链并明示你的假设。

**声称的影响**：登录用户被引导到任意外部站点（钓鱼落地页），
重定向发生在受信任域名的响应里。

请按 euthyna 阶段 C 给出裁定。
