# 断言

**位置**：`src/fetcher.js` 的 `fetchUrl`
**类别**：SSRF（服务端请求伪造）
**断言**：`fetchUrl` 对传入的 URL 没有任何主机或网段限制，URL 来自
dashboard 的导入表单（`POST /api/import`，请求体 `url` 字段）。任意登录用户
可让服务进程向任意可达地址发起 GET 请求并取回响应，包括部署内网中
只对内开放的地址。

**威胁模型**：`url` 来自请求体。断言未说明该路由的守卫强度，
请自行核验调用链并明示你的假设。

**声称的影响**：以服务进程的网络位置访问内部地址并取回内容
（经典 SSRF 原语；云元数据端点等由部署决定）。

请按 euthyna 阶段 C 给出裁定。
